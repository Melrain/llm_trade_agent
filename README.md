# LLMTradeAgent

用大语言模型整合行情、新闻与预测市场，自动做出交易决策并下单。程序化风控写在代码里，不合格的单会被拦下或改数量，通过的单会立刻发出去。

支持两个交易场所，在 **设置 → 交易场所** 切换：

- **MT5**：**BTC / ETH / 黄金** 现货报价（如 `BTCUSD` / `ETHUSD` / `XAUUSD`），默认黄金，仅 Windows（官方 Python 接口限制）。
- **OKX**：USDT 永续 `BTC-USDT-SWAP` / `ETH-USDT-SWAP`（黄金只走 MT5），Windows / macOS / Linux 都可跑行情；下单需要 OKX API Key。顶栏可立刻切换 **模拟盘 / 实盘**，两套密钥分开保存。

实验性项目，建议先在 Demo / 模拟盘跑通，再开实盘。

> 外汇与差价合约保证金交易具有高风险，可能导致本金全部损失。本软件不构成投资建议，过往表现不代表未来结果。

## 你需要准备什么

1. 一个 **OpenAI 兼容** 的 API Key（默认对接 [DeepSeek](https://platform.deepseek.com/)）。
2. **MT5 模式**：Windows 电脑，已安装并登录 [MetaTrader 5](https://www.metatrader5.com/)。Demo 或实盘都可以。
3. **OKX 模式**：OKX API Key / Secret / Passphrase。建议先开 [模拟盘](https://www.okx.com/)。模拟盘和实盘密钥分开保存，顶栏或设置里可随时切换。密钥用系统加密存在本机。

## 安装

到 [Releases](https://github.com/Melrain/llm_trade_agent/releases) 下载最新的 `llm_trade_agent-*-setup.exe`，按向导安装后打开 **LLMTradeAgent**。

安装后可在 **设置 → 关于** 检查更新。发现新版本后点「下载并重启」，会先关闭自动交易再覆盖安装。本机数据（API Key、决策记录）不会被清掉。

也可以从源码运行，见文末。

## 第一次使用

### 1. 打开并登录 MT5

- 登录你的 MT5 账户（建议先用 Demo）。
- 在 MT5 里打开 **工具 → 选项 → 专家顾问**，勾选 **允许算法交易**。
- 保持 MT5 开着。本应用通过本机桥接读取行情和下单，不会把账户密码上传到任何服务器。

打开客户端后，看顶栏右侧的 **MT5** 指示灯：绿灯表示行情在更新；灰/红灯表示未连上。常见原因：没开 MT5、没登录、没允许算法交易。

### 2. 填写 API Key

左侧点 **设置 → LLM**：

| 项 | 说明 |
| --- | --- |
| Base URL | 默认 `https://api.deepseek.com/v1`，可换成任意 OpenAI 兼容端点 |
| 模型 | 默认 `deepseek-v4-pro` |
| API Key | 填一次即可。用系统加密存在本机，留空保存表示不改 |
| Temperature | 0–0.5，越低越稳定 |

没填 Key 时，Agent 页和顶栏自动交易都无法启动。

### 3. 确认决策周期和风控

**设置 → 决策周期**

- 决策周期：15 分钟 / 30 分钟 / 1 小时。到点会自动跑一轮。
- **自动决策**：只调用模型、写决策记录，**不会下单**。关掉后周期循环停止，实弹总闸也会一起关。

**设置 → 风控**

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 手数上限 | 0.1 | 单笔最大手数，模型给再大也会被压住 |
| 单笔风险 % | 1% | 按止损距离反推手数，覆盖模型给的 volume |
| 固定手数 | 空 | 填写后按固定手数下，但仍不超过上限和单笔风险 |

日亏熔断固定为净值 **3%**，可在驾驶舱风险水位条看到，设置里改不了。

### 4. 先手动跑一轮

左侧点 **Agent**，点 **立即决策一次**。

这时会立刻跑一轮：读快照 → 模型决策 → 风控 →（若顶栏自动交易已开）直接下单。右侧能看到模型依据、动作、风控结论和成交回执。建议先关掉自动交易，确认链路正常后再打开。

### 5. 打开自动交易

顶栏右侧有 **自动交易** 开关。打开前会二次确认。打开后 Agent 会按周期**自动决策并直接下单**（Demo 和实盘都会发到 MT5）：

- 顶栏文字变为 **实弹**，驾驶舱会出现「自动交易中」。
- 之后每一轮（含「立即决策一次」）通过风控的开平仓都会发到 MT5。
- 随时再拨一次开关即可关掉，关掉后不再下单，但仍可手动跑决策看推理。
- 顶栏账户徽章是 **REAL** 时，用的是真实资金。确认框会额外警告。
- 从 Demo 换成实盘、或换了登录号时，总闸会自动关掉，避免在未确认的账户上发单。

这是高危操作。请先确认手数/张数与风险上限已经设好；不熟悉时请先用 Demo / OKX 模拟盘。

### 6. 改用 OKX 自动交易

1. **设置 → 交易场所** 选 **OKX · USDT 永续**。
2. 选品种 **BTC** 或 **ETH**（合约自动对应 `BTC-USDT-SWAP` / `ETH-USDT-SWAP`），再设杠杆、全仓或逐仓。黄金只走 MT5，在 OKX 下点黄金会切回 MT5。
3. 顶栏或设置里切到 **模拟盘**（推荐），填写该盘口的 API Key / Secret / Passphrase，点 **测试连接**。实盘密钥另存一套，切换时立刻生效。
4. **设置 → 风控** 里的上限此时按 **合约张数** 计，不是 MT5 手数。
5. 顶栏出现 DEMO / REAL 后，按上面第 4、5 步先手动决策再开总闸。

切换场所会自动关掉总闸。OKX 下单、持仓模式（净持仓 / 双向）和杠杆设置参考了你在 QUANT-BIGDATA-TREND / quant02 里的 `OkxTradeService`。

## 界面说明

左侧导航：

| 页面 | 做什么 |
| --- | --- |
| **驾驶舱** | 净值、今日盈亏、持仓、最近一次决策、日亏水位、下次决策倒计时 |
| **图表** | BTC / ETH / 黄金 K 线（M15 / H1 / H4 / D1），可叠 EMA、RSI。成交会标在图上，点击标记可回看当时推理。右侧可手工下单 |
| **Agent** | 决策时间线 + 单条详情（输入快照、推理、风控结论、成交回执） |
| **情报** | 新闻、Polymarket 隐含概率、财经日历。高影响事件临近时顶栏会锁开仓 |
| **复盘** | 胜率、盈亏比、累计盈亏曲线、已平仓列表 |
| **设置** | LLM、决策周期、风控、只读数据源 |

顶栏还能看到：品种现价、**BTC / ETH / 黄金** 切换、OKX 的 **模拟盘 / 实盘** 切换、Agent 是否在跑、净值与浮动盈亏、账户是 DEMO / REAL。

## Agent 怎么工作

每轮固定四步，任何一步都会落库：

1. **快照**：MT5 行情与持仓 + 新闻/日历 + Polymarket。
2. **LLM 决策**：输出结构化动作（开多 / 开空 / 持有 / 平仓 / 改止损）。
3. **风控守门**：硬编码规则，提示词绕不过去；手数也可能被改写。
4. **下单**：自动交易已开、账户类型可识别（Demo 或实盘）、风控通过时，立刻发到当前场所（MT5 或 OKX）。

被风控拒绝时不会下单，时间线里仍能看到原因。自动交易关闭时只记录决策，不会发单。

一句话：**决策通过即自动下单 · 风控由代码强制执行 · 每轮从快照到成交可回放。**

## 风控会拦什么

这些规则写在程序里，改提示词无效：

- 开仓必须带止损，距离须在 0.3–5 倍 H1 ATR 之间。
- 同品种已有持仓时不再开新仓。
- 置信度低于 0.6 拒单。
- 今日开仓最多 6 笔；连续亏损 3 笔后当天停开。
- 距上次开仓不足一个决策周期，拒单。
- 当日亏损达到净值 3%，熔断开仓。
- 高影响财经事件临近、点差异常、价格超过 5 分钟未动（疑似休市），暂停开仓。
- 手数由「单笔风险 % × 止损距离」计算，再被手数上限卡住。
- 浮盈超过 1 倍 H1 ATR 后，会把本引擎仓位的止损移到入场价（保本），总闸打开且账户类型可识别时生效。

## 常见问题

**顶栏 MT5 一直是灰/红的？**  
先开 MT5 并登录，勾选允许算法交易，周末或休市时行情不更新也属正常。

**点了「立即决策一次」没反应？**  
到设置确认已保存 API Key，并看 Agent 页是否有红色报错（Key 无效、额度不足、网络等）。

**打开了自动交易却没有单子？**  
可能被风控拒绝，到 Agent 时间线看 `reject` / `skipped` 原因。账户类型显示「未知」时引擎不会发单。REAL 徽章表示正在用真实资金下单。

**API Key 会不会上传？**  
不会。客户端本地运行，Key 用系统级加密存在本机。

**能保证盈利吗？**  
不能。LLM 的价值在跨源信息整合，不在预测价格。请先在 Demo 上跑足够久。

**支持哪些经纪商？**  
任意提供 MT5 的经纪商。品种目前是 **BTC / ETH / 黄金**。

**如何更新到新版本？**  
设置 → 关于 → 检查更新。有新版本时点「下载并重启」，会先关闭自动交易再覆盖安装。从源码发版请用 `npm run release:win`，或手动上传时不要漏掉 `latest.yml` 和 `.blockmap`。

**为什么只有 Windows？**  
MT5 官方 Python 接口仅支持 Windows。

## 从源码运行

需要 Node.js 22+ 与已安装的 MetaTrader 5。

```bash
git clone https://github.com/Melrain/llm_trade_agent.git
cd llm_trade_agent
npm install
npm run prepare:mt5-runtime
npm run dev
```

打包 Windows 安装包：

```bash
npm run build:win
```

发布到 GitHub Releases（需本机 `GH_TOKEN`，权限含 `repo`）：

```bash
npm run release:win
```

产物在 `dist/`。自动更新依赖同一次 Release 里的 `latest.yml`、`llm_trade_agent-*-setup.exe` 和 `.blockmap`；只手传 exe、漏传 yml 时，客户端检查更新会失败。

`prepare:mt5-runtime` 会下载嵌入式 Python 并安装 MT5 桥依赖，只需做一次。
